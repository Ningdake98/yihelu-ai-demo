# 方案A · 真人脸 AI 融合版｜锦创书城·颐和路店《颐和路书旅·民国AI换装打卡》 — 操作说明

纯前端 H5 原型（单文件 `index.html`），**无需部署服务器**，双击即可运行演示。
全页面**中英文双语**，右上角「EN ✓」开关可一键关闭英文；生成的海报 / 短视频 / 图鉴作品同样带有中英双文字。

> **方案A 核心亮点**：示例人像或用户上传的真人脸，经 **AI 人脸定位**后把五官脸型精准融入无脸服装模型的脸部位置，并**实测肤色、动态重绘模型脸部**，人脸与服装衔接处**零色差**，形成自然完美的民国打卡海报。

---

## 一、运行方式

1. **直接打开**：双击 `index.html`，用 Chrome / Edge 打开。
2. **推荐演示姿势**：`F12` → 设备模拟（`Ctrl+Shift+M`）→ 选择手机机型，查看移动端效果。
3. 地图、书封、背景、民国装束、示例人像均为 AI 图片接口实时生成，**首次打开需联网**。
4. **双语开关**：右上角「EN ✓」按钮，点击后全站英文隐藏（仅中文）；再点恢复中英双语。海报与短视频上的英文字样同样跟随此开关。
5. **每次打开 / 刷新均为未登录的初始启动页**（数据仅存内存，不落盘），方便比赛时从零演示；演示完成后可在「读书图鉴」页底部点「🚪 退出登录」回到启动页。

## 二、核心链路演示

> 实景地图 → 推荐拍照点位 → 文脉专属书单 → 金句品读 → AI民国换装打卡 → 海报/短视频自动入图鉴

### 第 1 步：启动页场景锁定
- 打开即加载「颐和路手绘街区地图」+「一景一书，读遍颐和」，点「进入街区，开始书旅 →」。

### 第 2 步：街区地图导览（一景一书 + TOP 3 拍照点）
- 地图**默认锁定完整显示**；5 个闪光点位：颐和路公馆区、梧桐大道、民国旧址群、锦创书城·颐和路店、文人旧居巷弄。
- 点击任一点位 → 历史文脉解读 + **TOP 3 推荐拍照点位**（G 谷歌实景 / A 高德导航 一键跳转官方地图软件）。

### 第 3 步：文脉书单与金句品读
- 「文脉书单」页展示首批 5 本颐和路限定书目，每本含简介、场景解读、10 句金句。
- 点金句右侧「选这句打卡」→ 自动跳转换装页并带上该金句。

### 第 4 步：AI 民国换装打卡（方案A核心）
1. **① 选性别与装扮**：女生 / 先生 × **学生装 / 日常装 / 礼服装** 三大类即时切换。
2. **② 选背景**：店内书香 / 颐和路梧桐街景。
3. **③ 获取人脸**：
   - **示例人像**（女/男）一键载入，零准备演示；
   - 或「打开相机」现场拍照 /「上传正面照」。
4. **④ AI 融合对位**：
   - 系统**自动识别人脸五官与脸型**，对齐到服装模型的脸部位置与大小（示例人像采用预标定脸框，100% 命中；上传照片走肤色区域 AI 检测）；
   - **AI 实测面部肤色**，并把服装模型的脸部预留区**重绘为同一肤色**——交界处无色差、无"贴图感"；
   - 脸缘径向羽化渐隐，五官自然融入；
   - 三个滑杆（上下 / 左右 / 大小 ±15%）可微调，服装模型会**自动按人脸比例放大适配**。

### 第 5 步：一键生成传播物料（自动入图鉴）
- 「🖼️ 生成打卡海报」：720×960 高清海报，自动下载并存入「读书图鉴」。
- 「🎬 生成短视频」：5 秒动态短视频（镜头缓推 + 落叶动效 + 金句 + 水印）自动下载并入图鉴，可在图鉴页直接播放。
- 「📚 存入颐和路读书图鉴」/「分享给朋友」：沉淀数字文创资产 / 调起系统分享。
- 图鉴页页底「🚪 退出登录」一键回到初始启动页。

## 四、常见问题

- **AI 图片不显示？** 首次需联网，等 2~5 秒或刷新；AI 图失败时自动回退莫兰迪渐变 + 手绘衣身，功能不受影响。
- **摄像头打不开？** 改用「上传正面照」或「示例人像」即可完整演示。
- **人脸贴合不准？** 用三个滑杆微调；系统 AI 定位已覆盖绝大多数正面照，滑杆仅作 ±15% 微调。
- **肤色会有色差吗？** 不会——系统在检测到的脸框内采样实测肤色，同时把模型脸部预留区重绘为同一肤色，交界处颜色完全一致。
- **短视频格式？** `.webm`（Chrome/Edge 直接播放、可导入剪映）；需要 `.mp4` 用剪映一键转封装。
- **换装原理？** 全部在浏览器本地完成：人脸仅本机处理不上传；衣装白底自动透明化（日常装背景透出、四肢保持不透明），真人脸 AI 定位 + 肤色迁移 + 羽化融合。
